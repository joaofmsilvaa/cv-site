# Brand guidelines: João Silva (personal CV site)

> Last updated: 2026-11-27 · Status: v1

## Positioning
Computer Engineering student from the Alentejo who builds software with AI (RAG, LLM APIs, ML). Audience: professors and tech recruiters. Job of the site: show what João has built and studied, fast, and invite a question to the CV chatbot.

## Voice
- First person, plain and concrete: name the project, the stack, the result.
- No hype adjectives ("passionate", "cutting-edge"). Facts from the CV only.
- Sentence case everywhere. Buttons say what happens ("Chat with my CV", "Email me").

## Colour
| Name | Hex | Usage |
|------|-----|-------|
| Cobalt (azulejo) | #1F3FBF | Hero, page headers, links, timeline accents |
| Ink | #0B1B3F | Body text, dark-mode background |
| Paper | #F6F7FB | Page background |
| Sky | #DCE4FA | Tags, quiet surfaces |
| Sun | #F2C230 | One use only: the chat call to action |
| Slate | #4A5675 | Secondary text (7.1:1 on Paper) |

Contrast: Ink on Paper 16:1; white on Cobalt 7.4:1; Ink on Sun 10:1.

## Typography
One family, **Archivo** (Google Fonts), using its width axis:
| Role | Setting |
|------|---------|
| Name / H1 | Archivo Expanded (wdth 125), 800, tight tracking |
| H2 / H3 | Archivo Expanded, 700 |
| Body | Archivo (wdth 100), 400, 17px, line-height 1.6 |
| Dates | Archivo 600, tabular numbers |

## Signature element
The azulejo tile: a geometric SVG pattern in translucent white over Cobalt, used only on the hero and page headers. Never on content areas.
