# João Silva: CV website + chatbot

- `content/`: CV data (JSON), edited through Decap CMS at `/admin`
- `src/`: Eleventy templates and CSS
- `admin/`: Decap CMS (GitHub backend, Netlify OAuth)
- `knowledge/`: chatbot training sources; `report/`: assignment report

Run locally: `npm install`, then `npm run dev` (site at http://localhost:8080, CMS at http://localhost:8080/admin/, no login needed locally).
